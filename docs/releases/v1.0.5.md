# Codex Workspace Hub v1.0.5

此版本的 Docker 发布被 Node 22 下的测试用例生命周期问题拦截。请使用修复构建检查后的 v1.0.6；保留此标签供追溯。

CW 和 Windows Token 采集器统一更新到 v1.0.5。

- 账号累计 Token 改用官方 `account/usage/read`，同一账号多台 PC 只统计一次。
- 官方尚未返回的当天数据保持缺失；周、月的部分日数据有明确标记。离线不再用额度百分比补增官方统计。
- 本机日志金额拆成已知价格 API 折算与未知价格估算，注明设备来源。官方账号费用不再用本地日志或默认单价冒充。
- 保留旧设备历史；支持失败缓存、账号切换隔离和过时上报保护。
- 本地扫描跳过相邻且累计值、单次值完全相同的重复 Token 通知；修正后本机日志计数和折算金额可能下降，官方账号总量不受影响。

先拉取 CW Docker 的 `v1.0.5`（或更新后的 `latest` / `stable`），再替换每台 PC 的 `CWUsageReporter.exe`。配置和连接 Key 无需重新填写。PC 需要已登录 ChatGPT，并安装支持该接口的 Codex。

金额当前只展示最近上报设备的日志明细，不汇总多设备费用。官方日数据可能延迟；周期日期采用 UTC。API 等价价值不代表 ChatGPT 实际账单。

Android 安装包仍为 v0.3.3-beta9，本次未修改；旧版移动端可能无法正确展示新协议的缺失数据和金额状态，请以 CW 管理页或新版 Windows 采集器为准。额度桥接功能不变。
