# Codex Workspace Hub v1.0.6

CW 和 Windows Token 采集器统一更新到 v1.0.6。此版本包含 v1.0.5 的账号统计修复，并修正了阻断 Linux 发布的 Node 22 超时测试用例；生产超时逻辑未改动。

- 账号累计 Token 改用官方 `account/usage/read`，同一账号多台 PC 只统计一次。
- 缺失的官方日数据保持缺失；周、月的部分数据有明确标记。离线不再根据额度百分比补增官方 Token。
- 金额按设备单独展示：已知价格 API 折算与未知价格估算分开，避免把本机日志费用当作账号账单。
- 保留旧设备历史，支持失败缓存、账号切换隔离和过时上报保护。
- 本地扫描跳过相邻且累计值、单次值完全相同的重复 Token 通知；本机日志计数和金额可能随之下降。

先拉取 CW Docker 的 `v1.0.6`（或更新后的 `latest` / `stable`），再替换各 PC 的 `CWUsageReporter.exe`。配置和连接 Key 保留。PC 需要已登录 ChatGPT，并安装支持该接口的 Codex。

金额只展示最近上报设备的本机日志明细，不相加多设备费用，也不代表 ChatGPT 实际账单。官方日数据可能延迟；周期日期采用 UTC。

Android 安装包仍为 v0.3.3-beta9，本次未修改；旧版移动端可能无法正确展示新协议的缺失数据和金额状态，请以 CW 管理页或新版 Windows 采集器为准。额度桥接功能不变。
